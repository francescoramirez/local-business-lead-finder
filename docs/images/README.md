# Screenshot instructions

Do not add fabricated UI renders. Capture the real desktop app at **1366×768** from **Demo Mode** so no real businesses appear.

```bash
python -m pip install -e ".[gui]"
leadfinder gui
```

Choose **Try Demo** (or Demo → Try Demo Mode). Reset Demo Data if you need a clean set.

Suggested captures (save as PNG in this folder):

| File | What to show |
| --- | --- |
| `search.png` | Search panel with cost preview and DEMO MODE banner |
| `pipeline.png` | Pipeline columns with mixed statuses |
| `analytics.png` | Learn → Analytics including campaign list-cost estimate |
| `insights.png` | Learn → Insights |
| `costs.png` | Search cost preview plus page comparison |
| `settings.png` | Settings → API (Configured / Not configured, no key visible) |

Owner checklist: Welcome, Demo banner, Search, cost preview, priority, Undo, pitch template, Compare, Pipeline, Analytics, Insights, About.
